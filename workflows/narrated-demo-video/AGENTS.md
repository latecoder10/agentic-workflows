# AGENTS.md — narrated-demo-video

If you're an AI coding agent and the user wants a silent screen recording
turned into a narrated video (voiceover, presentation video, "fix the
sync/pacing," "the voice tone shifts between cuts," etc.), read
[`README.md`](README.md) in this directory for the full workflow before
doing anything — it has the exact script invocations and, critically, the
lessons that keep the result from having sync bugs, tone-shift bugs, or
awkward silence. Don't improvise this from scratch; those failure modes were
each hit and fixed once already, and the fixes are documented, not just the
symptoms.
